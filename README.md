# Monlote Urbanizadora

Site institucional estático da Monlote Urbanizadora, publicado pela Vercel.

## Estrutura

- `index.html`: página inicial.
- `empresa.html`: apresentação institucional.
- `atuacao.html`: serviços e etapas de atuação.
- `portofino.html`: portfólio e galeria do empreendimento.
- `contato.html`: canais de atendimento e CTAs de WhatsApp.
- `styles.css`: estilos compartilhados e responsivos.
- `script.js`: navegação, animações, slides e integração comum com WhatsApp.
- `portofino.js`: filtros e modal exclusivos da galeria do Portofino.
- `assets/`: imagens e identidade visual utilizadas pelo site.
- `docs/`: documentação interna, excluída da publicação.

## Desenvolvimento local

O site não requer instalação ou etapa de build. Para visualizar com um servidor local:

```powershell
npx --yes serve . -l 4173
```

## Publicação

O projeto está vinculado à Vercel pelo diretório `.vercel/`. A produção pode ser atualizada com:

```powershell
vercel --prod
```
